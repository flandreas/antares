---
title: Release 2.0.0 - Antares is open source
---

Besides the usual bugfixes and improvement, Antares is now open source under the Apache 2.0 license. You can get the source repo on [GitHub](https://github.com/flandreas/antares-source).

Check out the [release letter](/docs/releases/release-2.0.0/index.html) for a more in-depth description of what has changed with the new release.
