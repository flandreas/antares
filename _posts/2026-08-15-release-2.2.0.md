---
title: Release 2.2.0 with AI Assistant
---

Various bugfixes, improvements and the new feature 'AI Assistant'.

The new sidebar with an AI Assistent that can do the following:
- Explain the current circuit
- Build a new circuit
- Change the current circuit

Users must add their OpenRouter API key (in the preferences under "AI Assistent"), or export it as a shell variable when working as DEV.

This is experimental and still has many limitations:
- Only a limited set of components is supported (input, output, gate, tai-state buffer, switch, LED, constant, splitter, concentrator, clock, subcircuits)
- The generated geometrical layout is rudimentary

Check out the [release letter](/docs/releases/release-2.2.0/index.html) for a more in-depth description of what has changed with the new release.
